# 内网穿透说明

## 为什么需要

默认情况下，服务只能通过 `http://127.0.0.1:8000` 访问，只有你自己能用。

想让别人访问，需要把本地服务映射到公网，这叫**内网穿透**。

---

## 当前方案：cpolar（已内置）

项目会自动启动 cpolar 并申请公网地址，无需手动操作。

### 安装配置（首次）

1. 访问 [cpolar.com](https://www.cpolar.com/) 注册
2. 登录后进入「验证」页面，复制 **Authtoken**
3. 下载 Windows 客户端并解压
4. 配置 token：

```powershell
.\cpolar.exe authtoken 你的authtoken
```

5. 把 `cpolar.exe` 放到 `tools/cpolar/` 目录

### 使用

```powershell
.\run.ps1
```

启动后会显示：

```
   🌍 公网访问     https://xxx.cpolar.top
      发这个链接给别人，他在任何网络都能访问
```

### 地址变化规则

| 情况 | 地址是否变化 |
|------|------------|
| 重启服务（默认复用） | **不变** |
| 加 `--new-tunnel` | 会变 |
| 超过 24 小时 | 可能变 |
| cpolar 进程被杀 | 下次会变 |

**结论**：只要 cpolar 窗口不被关闭，地址就稳定。

### 注意事项

- 启动时会弹出一个 cpolar 控制台窗口，**不要关闭**（可最小化）
- 免费版有流量限制（每月 2GB 左右）
- 服务关闭后隧道默认保留，别人仍能访问（除非加 `--kill-tunnel-on-exit`）

## 局域网访问

同一 WiFi 下不需要穿透：

```powershell
.\run.ps1 -NoTunnel
```

会显示：

```
   📡 局域网访问   http://192.168.x.x:8000
```

手机、平板连同一个 WiFi 就能访问。

**如果访问不了**，可能是防火墙：

```powershell
# 需管理员权限
.\run.ps1 -SetupLan
```

## 常见问题

### Q: 公网地址返回 404

**原因**：cpolar 进程已退出，但服务器上还留着域名记录。

**排查**：

```powershell
# 1. cpolar 进程还在吗
Get-Process cpolar

# 2. 重启服务
cd AI-Agent
..\.venv\Scripts\python.exe server.py
```

### Q: 显示「地址暂时不可达」

隧道刚建好需要 **10-30 秒**生效，等一会儿刷新即可。

### Q: 端口 8000 被占用

服务会自动切换到 8001、8002...，看启动日志里的实际端口。
