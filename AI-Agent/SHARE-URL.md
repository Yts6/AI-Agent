# 公网地址说明

## 地址怎么获取

```powershell
.\run.ps1
```

启动后控制台会显示：

```
   🖥  本机访问     http://127.0.0.1:8000
   📡 局域网访问   http://192.168.x.x:8000

   🌍 公网访问     https://xxx.cpolar.top
      发这个链接给别人，他在任何网络都能访问
```

**要发给别人的是最后那个「公网访问」地址。**

---

## 地址会变吗

cpolar 免费版的子域名**每 24 小时轮换一次**，不是每次重启都变。

| 操作 | 地址变化 |
|------|---------|
| 重启服务 | **不变**（复用已有隧道） |
| 加 `--new-tunnel` | 会变 |
| 超过 24 小时 | 可能变 |
| 关闭 cpolar 窗口 | 下次启动会变 |

### 保持地址稳定的方法

1. 启动时弹出的 cpolar 窗口**不要关闭**（可最小化）
2. 重启服务用默认参数（不加 `--new-tunnel`）

### 想换地址

```powershell
.\run.ps1 -NewTunnel
```

---

## 三种地址的用途

| 地址 | 谁能访问 | 场景 |
|------|---------|------|
| 🖥 本机 127.0.0.1 | 只有自己 | 日常开发 |
| 📡 局域网 192.168.x.x | 同一 WiFi 的设备 | 手机/平板测试 |
| 🌍 公网 xxx.cpolar.top | 任何网络 | 发给同学/老师 |

## 安全提醒

### 公网访问的风险

开启隧道后**任何人都能打开这个地址**：
- 他们会消耗你的 API 额度
- 可能上传恶意文件

### 建议设置访问密码

在 `.env` 里加：

```ini
ACCESS_PASSWORD=你的密码
```

重启服务后，打开网页会要求输入密码。

## 常见问题

### Q: 地址打不开（404）

cpolar 进程退出了。检查：

```powershell
Get-Process cpolar
```

没有输出就重启服务。

### Q: 换个网络后地址失效

公网地址依赖你本机的网络。换了 WiFi 或断网，隧道会重建，地址可能变。

### Q: 免费版有什么限制

- 每月流量约 2GB
- 地址 24 小时轮换
- 带宽有限（约 1Mbps）
