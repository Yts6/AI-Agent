# 公网地址说明

## 现状：地址是固定的

你现在的公网地址每次启动都一样：

```
https://d58aae9.r35.cpolar.top
```

### 为什么换不了

我实测验证了三件事：

| 尝试 | 结果 |
|---|---|
| 重启隧道 | 还是同一个地址 |
| `-subdomain` 自定义 | 免费版静默忽略（认证成功后不分配） |
| 换端口重启 | 地址跟账号绑定，与端口无关 |

**根因**：cpolar 免费版把**子域名和账号绑定**了。你注册时系统就分配了 `d58aae9`，之后所有隧道都用这个。

这不是脚本能绕过的，是服务端的账号策略。

---

## 想换地址，三个办法

### 办法一：换 cpolar 账号（最快）

注册一个新邮箱账号，拿到新的子域名。

```powershell
# 1. 去 cpolar.com 用新邮箱注册
# 2. 复制新的 authtoken
# 3. 重新配置
cd D:\Download\APP\cpolar
.\cpolar.exe authtoken 新token
# 4. 重新发布
cd D:\A-Code
.\share.ps1
```

**成本**：免费  
**缺点**：要管理多个账号

### 办法二：用 natapp（地址本来就每次变）

natapp 免费版的特性是**每次启动分配随机地址**，正好符合你的需求。

1. https://natapp.cn 注册 + 实名认证
2. 「我的隧道」→ 购买免费隧道，类型 Web，端口 8000
3. 下载客户端
4. 运行：

```powershell
.\natapp.exe -authtoken=你的token
```

输出里的 `http://xxxx.natappfree.cc` 每次启动都不同。

**成本**：免费（需实名）  
**优点**：地址真的每次变

### 办法三：升级 cpolar 付费版

付费版支持自定义子域名，可以主动换。

**成本**：约 10-20 元/月  
**优点**：可控、稳定

---

## 我的建议

### 如果你只是不想一直用同一个

其实**固定地址更方便**——发给别人的链接不会失效，不用每次重新告知。

你最初的需求是每次换一个，但如果对方要反复访问，固定地址反而更好。

### 如果你确实需要每次不同

推荐 **natapp**，免费且天然满足需求。就是需要做一次实名认证。

## 脚本说明

`share.ps1` 会自动：
- 清理旧隧道
- 确保 Web 服务运行
- 开新隧道
- 解析并高亮显示地址
- 复制到剪贴板

虽然地址是固定的，但脚本省去了手动操作。

```powershell
cd D:\A-Code
.\share.ps1
```
