# 项目技术文档

## 缓存策略

系统采用两级缓存架构。本地 LRU 缓存容量为 500 条，用于热点数据快速响应。
Redis 分布式缓存过期时间设置为 3600 秒，保证多实例数据一致。
整体缓存命中率目标为 85% 以上，低于该值需要排查缓存穿透和雪崩问题。

## 部署方案

使用 Docker Compose 部署，包含 3 个服务：web 前端服务、api 后端服务、redis 缓存服务。
API 服务默认启动 4 个 worker 进程，单实例 QPS 压测结果约为 1200。
压测环境为 8 核 16G，使用 wrk 工具持续压测 5 分钟。

## 监控指标

核心监控项包括三项：接口 P99 延迟（阈值 200ms）、错误率（阈值 0.5%）、缓存命中率（阈值 85%）。
任一指标超过阈值会触发企业微信告警，告警消息包含指标名、当前值、阈值和发生时间。
监控数据保留 30 天，使用 Prometheus 采集、Grafana 展示。

## 故障处理

缓存击穿时启用互斥锁，只允许一个请求回源。
缓存雪崩时给过期时间加随机偏移，避免同时失效。
Redis 主从切换自动完成，切换期间降级为本地缓存。
